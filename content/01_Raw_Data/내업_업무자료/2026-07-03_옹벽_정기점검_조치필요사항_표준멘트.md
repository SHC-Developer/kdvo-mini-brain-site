# 옹벽 정기안전점검 — 조치필요사항 표준 멘트

> **대한민국상이군경회시설사업소** 내부 통일 문구.  
> 적용: 정기안전점검 **실시결과 요약표** 「조치필요사항」란.  
> 확정일: 2026-07-03

## 표준 멘트 (복사용)

| 구분 | 적용 조건 | 조치필요사항 멘트 |
|------|-----------|------------------|
| **경미한 손상** | 현재 확인된 경미한 결함·손상(진행·보수 판단 전 단계) | `주의관찰 필요(반기 1회, 육안․외관조사, 진전 여부 확인)` |
| **보수한 손상** | **모든 손상 항목** 공통(식생 제외) — 보수 완료, 금회 해당 부위 특이 손상 없음 | `보수부위 재손상 여부 경시관찰(정기안전점검 시 동일 부위 육안․외관조사)` |
| **배수공 — 세립토 유출** | 배수공에서 세립토 유출 관련 손상(보수 전·미보수) | `주의관찰 필요(우기 시 세립토 유출 흔적 여부 확인)` |
| **배수공 — 누수흔적** | 누수흔적 관련 손상(보수 전·미보수) | `주의관찰 필요(우기 시 습윤 상태 및 세립토 흔적 확인)` |
| **배수공 — 막힘** | 배수공 막힘 관련 손상(보수 전·미보수) | `주의관찰 필요(우기 시 배수 여부 확인)` |
| **배수로 — 이물질 퇴적** | 배수로·측구·집수정·배수구 등 이물질·퇴적물 확인 | `퇴적물 제거 조치 필요` |
| **식생 — 발생** | 사면·비탈면·표면보호부 등 식생 확인(제거 전) | `식생 제거 조치 필요` |
| **식생 — 제거 완료** | 식생 제거(보수) 완료, 금회 해당 부위 재발 없음 | `식생 재발생 여부 경시관찰(정기안전점검 시 동일 부위 육안․외관조사)` |

## 사용 메모

- **경미한 손상**: 점검결과에 손상 내용을 기재한 뒤 위 멘트 사용.
- **보수한 손상**: **체크리스트 모든 항목**(균열·배수공·누수·철근노출 등, **식생 제외**) 공통. 보수 완료·금회 특이 손상 없을 때 사용. 점검결과에 보수 일시·공법 및 금회 이상 없음 기재. `2.1 다. 보수·보강 이력`과 연계.
- **배수공 3종**: RAW-013 표 3-4 「4. 배수공」·「5. 전면부 누수」 구분. 보수 완료 시 **보수한 손상** 멘트. 우기 관찰 3종은 **우기 시 확인** 명시.
- **배수로 퇴적**: 「15. 비탈면 배수시설」 이물질·퇴적 → `퇴적물 제거 조치 필요`
- **식생 발생**: 식생 확인(제거 전) → `식생 제거 조치 필요`
- **식생 제거 완료**: → `식생 재발생 여부 경시관찰(정기안전점검 시 동일 부위 육안․외관조사)`. 점검결과에 제거 일시·금회 재발 없음 기재.
