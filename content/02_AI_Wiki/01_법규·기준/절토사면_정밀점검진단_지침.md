# 절토사면 정밀안전점검·진단 지침 정리 (주제1)

> 지침 3종(과업지시서 RAW-016 · 표준서식 RAW-017 · **세부지침 제14장** RAW-018)의 **공통 지침**을 정밀안전점검 / 정밀안전진단으로 정리.  
> 최상위 기술기준은 **세부지침 §14**(RAW-018). Query 허브 → [[절토사면_점검진단_허브]]

---

## 1. 적용 범위·대상 (세부지침 §14.1)

- **제2종시설물**: 연직높이(옹벽 있으면 옹벽 상단부터) **30m 이상** 포함 절토부로서 단일 수평연장 **100m 이상**인 절토사면 (도로·철도·항만·댐·건축물 부대시설).
- **대상 시설** [표 14.1]: 기본시설물(상부자연사면·사면·사면하부), 부대시설물(보호·보강·배수처리·이격거리내 시설), 공중이용부위(추락방지시설·도로포장·도로부 신축이음부·환기구 덮개) — **정기/정밀점검/정밀진단 모두 동일 대상**.
- **중대한 결함** [§14.1.4]: 사면 손상상태 평가 **"d" 이하**인 경우 → **조정 불가**. 공중이용부위 평가 "d" 이하도 중대결함.

## 2. 현장조사 항목 — 점검 단계별 (세부지침 §14.2)

정기점검[표14.2] → 정밀안전점검[표14.3] → 정밀안전진단[표14.5]로 갈수록 심화. 공통 조사영역:

- **사면 손상상태**: 파괴징후(①인장균열 ②지반변형 ③구조물변형), 파괴현황(④유형·위치·규모).
- **사면 파괴요인**: 지반상태(토질조건·토층심도·절리 특성), 사면형상(경사·집수지형), 자연외부요인(강우·지하수), 인위외부요인(표면보호·절취·보강공·배수조건), 계측기 점검.
- **공중이용부위**: 추락방지시설·도로포장·신축이음부·환기구 덮개 상태.

### 조사영역·사면 분할 [§14.2.2]
- 사면 분할: 우측=시점, 좌측=종점, **수직고 5m 이하** 지점에서 분할.
- 구간 분할(상태·안전성평가용) — 다음 중 하나면 분할, **미분할 시 사유를 보고서에 기재**:
  1. 구성재료(토사/연약암반/파쇄암반/절리암반) 수평 변화
  2. 사면 경사방향 **40° 이상** 변화
  3. 동일구간 연장 **200m 이상**

## 3. 재료시험 기준수량 (세부지침 §14.3, [표14.16·14.17])

| 항목 | 정밀안전점검 | 정밀안전진단 |
|------|:------------|:------------|
| 토양경도(토사) | 상·중·하부 3 | 3 |
| 표준관입/전단저항각(토사) | **생략 가능** | 시추 1, 시료 3 |
| 토질분류(함수비·애터버그·비중·입도) | **생략 가능** | 각 3 |
| 슈미트해머 반발경도(암반) | 현장조사(20타격점) | 현장조사 |
| 일축압축시험(암반) | **생략 가능** | **3회** |
| 절리면 전단시험(암반) | **생략 가능** | **1회** |
| 불연속면 특성(방향·간격·연장·거칠기·간극·충전·누수·블록) | 육안·현장조사 | 현장조사 |
| 시추조사 | (원칙 미실시) | 필요시 시행 |

- **불연속면 조사** [§14.2.3(5)⑤]: 정밀점검=육안 대표 **3개조**, 정밀진단=**선조사법(10m+ 측선)·조사창측정법**, 노두 없으면 시추 후 공내조사(**80~300개, 150개 적정**).
- 풍화등급: ISRM **6단계**(F/SW/MW/HW/CW/RS)로 기록 [표14.6].

## 4. 상태평가 (세부지침 §14.4) — 점검·진단 공통

- **사면 분류** [표14.18]: 토층심도율 SR=토층심도/사면높이, 블록크기비 BR=Ib/H로 토사·연약암반·파쇄암반·절리암반사면 구분(혼합사면 0.2~0.4).
- **결함지수 F**: 손상상태지수 f1(합/24) + 파괴요인지수 f2(유형별 총점) → F로 **A~E 5등급** [표14.21].
  - 총점: 토사·연약암반 92, 파쇄암반 88, 절리암반 84.
- 진행성 인장균열·변형 확인 시 등급 **하향 + 정밀안전진단** 실시.
- **공중이용부위**(추락방지·도로포장·신축이음·덮개) 각 a~e 별도 평가 [§14.4.2 다].

## 5. 안전성평가 (세부지침 §14.5) — **정밀안전진단 시 실시**

- 원칙: **정밀안전진단 시 실시**. 정밀안전점검·긴급점검은 **선택과업**으로 가능하나, 결함이 광범위·중대하면 법 §12①에 따라 정밀안전진단 실시.
- **정밀점검 결과 → 정밀안전진단 실시 요건** [§14.5.1 2)(가)]: 인장균열·지반변형·구조물변형의 **진행성** 확인 시.
- **안전성평가 실시 요건** [§14.5.1 2)(나)]: 상태기준 **D 이하** 판정 또는 전문가 요구 시.
- 해석법: **평사투영해석**(암반, 파괴유형 정성 분석) + **한계평형해석**(원호·평면·쐐기, 안전율). 허용안전율 [표14.24] 건기 1.5 / 우기 1.2(1.3) / 내진 1.1.

## 6. 종합평가 (세부지침 §14.6)
- 상태평가·안전성평가 결과 중 **최저등급**을 종합평가 결과로 결정 [표14.28].
- **정밀안전점검**: 상태평가 결과가 종합평가(안전성평가 미수행 시 상태평가로 갈음).
- **정밀안전진단**: 상태평가 + 안전성평가 → 최저등급.

## 7. 보수·보강 (세부지침 §14.7)
4종: ①경사완화·구조물 보강(절취·록볼트·앵커·소일네일링·억지말뚝·옹벽 등) ②표면보호(식생·격자·숏크리트) ③낙석방지(뜬돌제거·방지망·울타리·피암터널) ④배수(산마루측구·소단배수로·도수로·수평배수공·집수정).

## 8. 과업지시서(발주) 요구사항 핵심 (RAW-016)
- 자료수집·현황도·상태변화 점검항목·현장조사/재료시험·상태·종합평가·보수보강·보고서·안전점검편람·일상점검매뉴얼.
- 사전검토보고서(착수 15일)·과업수행계획서(20일)·자문회의(3단계)·건설기술심의.
- 중대결함·신규결함·**보수부위 재결함** 별도 서면보고(미이행 시 "성실 미수행").
- 성과품: 종합/요약보고서, 외관조사망도(A3), 보수보강개요도, 사진첩, 안전점검편람, 일상점검매뉴얼, FMS DB.
