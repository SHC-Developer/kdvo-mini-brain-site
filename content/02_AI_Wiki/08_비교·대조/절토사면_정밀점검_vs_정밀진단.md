# 절토사면 정밀안전점검 vs 정밀안전진단 — 과업수행 차이 (주제3)

> "정밀안전진단을 수행해야 되면 정밀안전점검과 비교해 **추가로 수행되는 것**은?"에 대한 정리.  
> 근거: 세부지침 §14 [표14.3·14.5·14.16·14.17], §14.5 (RAW-018) + 과업지시서(RAW-016).

## 비교 대상·기준
- **비교 대상**: 절토사면 정밀안전점검 / 정밀안전진단
- **기준**: 현장조사 심도, 재료·실내시험, 지반조사, 안전성평가, 산출물

## 한눈에 보는 차이표

| 과업 | 정밀안전점검 | 정밀안전진단 | 근거 |
|------|-------------|-------------|------|
| **기본 성격** | 외관·현장측정 중심, **정성적** | 결함·손상 **원인 규명 + 보수·보강 제시**, **정량적** | §14.2, [표14.5] |
| **지반강도(토질)** | 육안 + 토양경도계·휴대용 콘 | **N치·전단저항각**(시추·표준관입) | §14.2.3(4)① |
| **토층심도** | 육안관찰 | **측량·물리탐사·자료조사** | §14.2.3(4)② |
| **불연속면** | 육안 대표 **3개조** | **선조사법·조사창측정법** (노두 없으면 공내조사 80~300개, 150 적정) | §14.2.3(5)⑤ |
| **암석 강도** | 슈미트해머 20타 → 일축압축강도 **추정** | 실내 **일축압축 3회**(직접) | [표14.17] |
| **절리면 전단시험** | **생략 가능** | **1회 이상** (수직응력 달리 5회+) | [표14.17], §14.2.5(나)③ |
| **토질 실내시험** | 생략 가능 | 토질분류·전단강도·표준관입 각 **3개 이상** | [표14.16] |
| **지표·지질조사** | (선택) | 지질구조대(단층·습곡·파쇄대), 선(창)조사법 | [표14.5] |
| **물리탐사** | 원칙 미실시 | 관찰 곤란 시 **전기비저항·탄성파·GPR 중 1+** | [표14.5] |
| **시추조사** | 원칙 미실시 | 코어 채취·지하수위·공내 절리방향 | [표14.5] |
| **안전성평가** | **선택과업** (D↓ 또는 진행성·전문가 요구 시) | **필수** (평사투영+한계평형) | §14.5.1 |
| **계측** | 기존 계측기 점검 | 필요 판단 시 **계측계획·설치** [표14.15] | §14.2.6 |
| **종합평가** | 상태평가로 갈음(안전성 시 최저) | 상태 + 안전성 → **최저등급** | §14.6.2 |
| **산출물** | 상태·안전등급, 외관조사망도 | + **안전성 해석·계산기록, 보수·보강 대책·공사비** | §14.5, RAW-016 §4 |

## 정밀안전진단에서 "추가로" 수행되는 핵심 (Δ)

1. **지반정보의 정량화**: 시추조사 + 물리탐사(필요시) + 토질·암석 **실내 물성시험** → 강도정수(점착력·내부마찰각·단위중량·탄성계수 등) 확보.
2. **불연속면 통계분석**: 선조사법/조사창측정법으로 다수 자료 획득 → 평사투영 정밀 도시.
3. **안전성평가(필수)**: 평사투영해석으로 파괴유형 결정 → 유형별 **한계평형해석**(원호/평면/쐐기)으로 안전율 산정, 허용안전율([표14.24]) 대비 A~E.
4. **계측 계획·설치**: 진단 결과 필요 판단 시 계측기 설치·모니터링([그림14.5] 흐름도).
5. **보수·보강 대책**: 원인 규명 → 공법 비교·선정, 시공개요도, **예정공사비 산출**(과업지시서 §4).
6. **사전조사 확대**: 기초자료(지질도·단면도·항공사진·강우·재해기록)·설계도면 검토 [표14.4].

## 진단으로 넘어가는 트리거 (정밀점검 → 정밀진단)
- 인장균열·지반변형·구조물변형의 **진행성** 확인 (§14.5.1 2가).
- 상태평가 **D 이하** 또는 사면 손상상태 **"d" 이하 중대결함**.
- 전문가 안전성평가 요구.
