# 2026-07-03 옹벽 조치필요사항 표준 멘트 요약

- **source_id**: RAW-20260703-015

## 핵심 5점
1. **실시결과 요약표** 「조치필요사항」란 **회사 확정** 통일 문구 (2026-07-03)
2. **경미한 손상** → `주의관찰 필요(반기 1회, 육안․외관조사, 진전 여부 확인)`
3. **보수한 손상** → `보수부위 재손상 여부 경시관찰…` — **식생 제외** 모든 항목 공통
4. **배수공** 3유형(세립토 유출 / 누수흔적 / 막힘) → 각각 **우기 시** 확인 멘트
5. **배수로 퇴적** (#15) → `퇴적물 제거 조치 필요`
6. **식생 발생** → `식생 제거 조치 필요` / **제거 완료** → `식생 재발생 여부 경시관찰(정기안전점검 시 동일 부위 육안․외관조사)`
7. 배수공은 RAW-013 표 3-4 「4. 배수공」·「5. 전면부 누수」와 구분 적용
