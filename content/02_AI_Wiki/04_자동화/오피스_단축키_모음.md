# 오피스 단축키 모음 (엑셀·한글)

> 보고서 작성 시 자주 쓰는 엑셀·한글(HWP) 단축키 빠른 참조. 질문 시 바로 조회용.

## 엑셀 단축키

| 순 | 내용 | 단축키 |
|:-:|------|--------|
| 1 | 열 너비 붙여넣기 | `Ctrl` → `W` |
| 2 | 직전 작업 반복 | `F4` |
| 3 | 위 셀 내용 복사 | `Ctrl+D` |
| 4 | 왼쪽 셀 내용 복사 | `Ctrl+R` |
| 5 | 행 전체 선택 | `Shift+Space` |
| 6 | 열 전체 선택 | `Ctrl+Space` |
| 7 | 행 또는 열 삭제 | `Ctrl+-` |
| 8 | 행 또는 열 추가 | `Ctrl+Shift+ +` |
| 9 | 데이터 범위 한 번에 선택 | `Ctrl+Shift+방향키` |
| 10 | 자동 합계(SUM) | `Alt`→`H`→`U`→`S` |
| 11 | 오른쪽 시트로 이동 | `Ctrl+PageDown` |
| 12 | 왼쪽 시트로 이동 | `Ctrl+PageUp` |

**추가 팁**
- 컬럼명이 길어 열이 안 보일 때: `Ctrl+1` → 맞춤 → 방향 **60도** 설정 (열 안 늘려도 컬럼명 표시)
- 열 너비 데이터에 맞게 자동 조정: `Alt`→`H`→`O`→`I`
- 표기법: `→` = 순서대로 하나씩, `+` = 동시에 누름

## 한글(HWP) 단축키 — 표(表) 관련

| 순 | 내용 | 단축키 |
|:-:|------|--------|
| 1 | 표 만들기 | `Ctrl+N`→`T` |
| 2 | 줄 추가 | `Ctrl+Enter` |
| 3 | 전체 블록 잡기 | `F5+F5+F5` |
| 4 | 자동 채우기 | `A` |
| 5 | 표 앞에 커서 깜빡이게 | `Shift+ESC` |
| 6 | 줄·칸 추가/삭제 | `Alt+Insert` / `Alt+Delete` |
| 7 | 표 나누기 | `S` |
| 8 | 엑셀 내용 복붙 | `Ctrl+C`, `Ctrl+V` |
| 9 | 표 음영 없애기 | `Alt+L` |
| 10 | 그래도 음영 안 없어지면 | `Alt`→`Y`→`바탕글` |
| 11 | 세로줄 블록 잡기 | `F5+F7` |
| 12 | 표 사이즈 조절 | `Ctrl`/`Alt`/`Shift` + 방향키 |
| 13 | 표 너비 같게 | `W` |
| 14 | 세로줄·가로줄 블록 잡기 | `F5+F7` (또는 `F8`) |
| 15 | 글자 굵게 | `Ctrl+B`(추정 — 원본 캡처 일부 가려짐, 확인 필요) |
| 16 | 글자 가운데 정렬 | `Ctrl+Shift+C` |

> 3~7, 11, 14번은 **표 안 블록 선택 모드**가 활성화된 상태를 전제로 함.
