# 옹벽 정기점검 평가방법

> **2026 제3종 매뉴얼** 제4장 §4.3. 체크리스트 항목별 **a~e** 판정 기준.

## 출처
- RAW-013 §4.3 (p.70~)

## 평가항목 요약 (주요시설)

### 1. 전면부 파손·손상 (콘크리트·보강토·석축)
| 등급 | 기준 (요약) |
|------|-------------|
| a | 손상 없음 |
| b | 경미, 추가 진행 가능성 없음 |
| c | 경미하나 추가 진행 가능성 있음 |
| d | 주요부 손상, 안전성 저하·확대 위험 |
| e | 기능상실·파괴 위험 |

### 2. 전면부 철근노출 (콘크리트)
| 등급 | 면적률 |
|------|--------|
| a | 없음 |
| b | 0% 초과 ~ 1% 미만 |
| c | 1% ~ 3% 미만 |
| d | 3% ~ 5% 미만 |
| e | **5% 이상** |

### 3. 전면부 이격 (보강토·석축)
| 등급 | 기준 |
|------|------|
| b | 1개소 이하 |
| c | 3개소 이하 |
| d | 4개소 이하 |
| e | **5개소 이상** 또는 안전 영향 |

### 11. 진행성 배부름 (보강토·석축·돌망태)
- **d·e** → 전체 안전등급 **강등** 규칙 적용 ([[옹벽_정기점검_체크리스트]])
