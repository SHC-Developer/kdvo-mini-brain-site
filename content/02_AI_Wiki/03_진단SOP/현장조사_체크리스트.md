# 현장조사 체크리스트

> **옹벽** 정밀안전점검·정밀진단 현장조사 (세부지침 §13.2). 정기점검은 [[옹벽_정기점검_체크리스트]].

## 출처
- RAW-012 §13.2

## 공통 조사 (§13.2.1)

| 항목 | 내용 |
|------|------|
| 선형·수준측량 | 시점~종점; 준공도면·기존 점검과 비교 |
| 배수상태 | 지표수·지하수 유입, 배수공·측구 |
| 재료시험 | 필요 시 보강재·견칫돌·철망 등 (§13.3) |
| 뒷채움 (보강토) | 입도분포시험 (안전성평가 연계) |

## 재료형식별 평가요소

→ [[옹벽_상태평가_요약]] §13.2.1 상세

| 형식 | 핵심 조사 |
|------|----------|
| 콘크리트 | 균열, 철근노출, 배수공, 누수, 기초 세굴 |
| 보강토 | 이격, 진행성 배부름, 뒷채움 유실 |
| 석축 | 채움콘크리트, 암석 풍화 |
| 돌망태 | wire mesh, 채움재, 결속철망 |

추락방지시설 · 도로포장 · 신축이음부 · 환기구 덮개
